Our Programmes

CodeBridge offers practical technology programmes that equip young people with valuable digital skills. Each programme is designed to help learners develop confidence, gain hands-on experience, and prepare for future employment opportunities in the technology industry.

Every programme below includes a week-by-week curriculum, so you know exactly what you'll be learning before you apply — click “View Full Curriculum” on any programme to see the full breakdown.

Web Development Bootcamp

This beginner-friendly programme introduces learners to the fundamentals of web development. Students learn how websites are created while building responsive web pages and interactive features.

Programme Details

  • Skill Level: Beginner
  • Duration: 8 Weeks
  • Prerequisites: None
  • Schedule: Saturdays (09:00–13:00)
  • Certificate: Issued upon successful completion
View Full Curriculum
  1. Week 1: Introduction to the Web & How Websites Work
  2. Week 2: HTML Fundamentals — structure, tags, semantic elements
  3. Week 3: HTML Forms & Tables
  4. Week 4: CSS Fundamentals — selectors, box model, colours
  5. Week 5: CSS Layout — Flexbox & Grid
  6. Week 6: Responsive Design & Mobile-First Principles
  7. Week 7: Introduction to JavaScript — variables, functions, events
  8. Week 8: Final Project — Build & Present a Personal Portfolio Site

Java Programming Fundamentals

This intermediate programme develops problem-solving skills through Java. Learners explore object-oriented programming, write applications, and gain practical coding experience for future software development careers.

Programme Details

  • Skill Level: Intermediate
  • Duration: 10 Weeks
  • Prerequisites: Basic computer literacy
  • Recommended: Web Development Bootcamp
  • Schedule: Tuesdays & Thursdays (17:00–19:00)
  • Certificate: Issued upon successful completion
View Full Curriculum
  1. Week 1: Introduction to Java & Setting Up the Development Environment
  2. Week 2: Variables, Data Types & Operators
  3. Week 3: Control Flow — Conditionals & Loops
  4. Week 4: Arrays & Basic Data Structures
  5. Week 5: Methods & Functions
  6. Week 6: Introduction to Object-Oriented Programming — Classes & Objects
  7. Week 7: Inheritance, Polymorphism & Encapsulation
  8. Week 8: Exception Handling & Debugging
  9. Week 9: File Handling & Simple Data Persistence
  10. Week 10: Final Project — Build a Console-Based Application
